# Nero roadmap

## 0.1 — foundation

- [x] Rust workspace
- [x] filesystem-backed notes
- [x] note creation
- [x] listing
- [x] opening/editing via `$EDITOR`
- [x] search
- [x] `[[links]]`
- [x] backlinks
- [x] daily notes
- [x] doctor
- [x] TUI command scaffold

## 0.2 — document intelligence

- [ ] Comrak Markdown parser
- [ ] frontmatter metadata
- [ ] robust wiki-link resolution
- [ ] SQLite FTS5 index
- [ ] file watcher
- [ ] snippets and ranking
- [ ] images and code-block metadata

## 0.3 — TUI

- [ ] Ratatui reader
- [ ] command palette
- [ ] search picker
- [ ] backlinks panel
- [ ] recent notes
- [ ] context panel
- [ ] terminal math rendering

## 0.4 — GUI

- [ ] Tauri shell
- [ ] beautiful Markdown renderer
- [ ] KaTeX
- [ ] split editor/reader
- [ ] command palette
- [ ] native file watching

## Later, only if needed

- [ ] Git helpers
- [ ] export to HTML/PDF
- [ ] optional synchronization
- [ ] embedded editor

## Non-goals

Nero is not intended to become a general project-management suite.
